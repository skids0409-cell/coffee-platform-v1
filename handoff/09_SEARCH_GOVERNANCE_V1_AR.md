# حوكمة البحث V1 — Search Governance

## القرار التشغيلي

- محرك المنصة وقاعدة البيانات ينفذان البحث اليومي بصورة حتمية وسريعة.
- الذكاء الاصطناعي يمكنه تحليل الاستعلامات واقتراح مصطلحات، لكنه لا يفعّل قاعدة بحث ولا ينشر محتوى تلقائياً.
- مسؤول البحث والتصنيف يراجع المقترحات ويعتمدها من لوحة `/operations`.
- في مرحلة بغداد يمكن لمدير المنصة تولي الدور، ثم يفصل لاحقاً إلى `Search & Taxonomy Manager`.

## خط المعالجة

1. توحيد الهمزات والتشكيل والمسافات وعلامات الترقيم.
2. مطابقة الاستعلام مع قاموس `search_terms` الخاص بسوق `IQ-BGD`.
3. تحديد المقصد ونطاق الكيانات وترتيبها.
4. استرجاع السجلات المنشورة حصراً.
5. ترتيب التطابق: الاسم الكامل، بداية الاسم، وجوده في الاسم، الوصف، المرادف.
6. عرض النتائج في مجموعات: المنتجات، المصادر، المعرفة، الجهات.
7. تسجيل حدث جودة مختصر في `search_query_events` من دون مستخدم أو IP أو جهاز أو جلسة.
8. إظهار الكلمات بلا نتائج أو ذات نتيجة واحدة في لوحة الإدارة.

## قاموس البداية

يتضمن الإصدار الأول كلمات القهوة العامة، الفلتر، الإسبريسو، التركية، المطاحن، مكائن التحميص، المحامص، المقاهي، موردي المعدات، مصادر القهوة، إثيوبيا، قوجي، الأدلة والتنظيف. لكل مصطلح:

- اسم عربي وإنجليزي.
- صيغة موحدة ومرادفات.
- مقصد رئيسي.
- نطاق كيانات مرتب.
- نمط مطابقة ووزن.
- أساس القرار وحالة النشر.

## صلاحيات الإدارة

- الجمهور يقرأ المصطلحات الفعالة فقط.
- الجمهور يستطيع إرسال حدث جودة مقيد فقط.
- المدير يرى المصطلحات والمسودات وتقارير الكلمات الضعيفة.
- إضافة مصطلح جديد تحفظه كمسودة.
- التفعيل يحتاج تأكيداً صريحاً ويسجل في `audit_events`.
- الإيقاف لا يحذف السجل؛ يحوله إلى `retired` للمراجعة التاريخية.

## الخصوصية والاحتفاظ

- لا تخزن هوية المستخدم أو عنوان IP أو معلومات الجهاز أو معرف جلسة.
- يخزن النص بعد التنظيف وبحد أقصى 80 حرفاً مع أعداد النتائج فقط.
- قبل الإطلاق العام يجب اعتماد سياسة احتفاظ وحذف دوري، وإضافة حماية معدل الطلبات على مستوى الحافة.

## معيار القبول

- «قهوة» تعرض العائلات الأربع في مجموعات.
- «محمصة» تعطي الجهات أولاً ولا تساوي ماكينة تحميص.
- «ماكينة تحميص» تعطي المنتجات أولاً.
- «قوجي» تعطي المصدر ثم المنتجات والمحتوى المرتبط عند نشر البيانات.
- الكلمات بلا نتائج تظهر في لوحة الإدارة.
- لا يستطيع الجمهور رؤية المسودات أو تغيير القاموس.
- يبقى `public_launch_enabled=false` حتى قرار المالك.
