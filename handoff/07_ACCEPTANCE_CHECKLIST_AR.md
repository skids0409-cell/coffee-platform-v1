# قائمة القبول النهائية

## معمارية المنتج

- [x] بغداد مثبتة كسوق أول.
- [x] البن الأخضر مؤجل ومكائن التحميص ضمن V1.
- [x] المنتجات والجهات والمصادر والمحتوى كيانات منفصلة ومترابطة.
- [x] صفحة البائع الداخلية هي الوجهة؛ الرابط الخارجي دليل توثيق، والدفع مؤجل.
- [x] بطاقة المنتج الرئيسية مستقلة عن عرض البائع وسعره وصوره.
- [x] طلبات الجهات لا تنشر مباشرة وتدخل طابور المراجعة.

## المعلومات والتصنيف

- [x] العائلات الرئيسية والفئات الفرعية ممثلة.
- [x] فلاتر المطاحن ومكائن التحميص خاصة بالفئة.
- [x] القيم المفقودة لا تُستنتج.
- [x] عينة بيانات بغداد معتمدة ومنشورة.

## تجربة المستخدم

- [x] بحث وتصفية وترتيب ومقارنة ومفضلة وCoffee Finder.
- [x] الرجوع من المنتج يحفظ الفلاتر والترتيب والموضع.
- [x] حالات تحميل وفراغ وخطأ وعدم نشر.
- [x] RTL وهاتف ولوحة مفاتيح وتقليل حركة.
- [ ] اختبار وصول على أجهزة فعلية.

## التقنية والأمان

- [x] RLS للكيانات المعروضة.
- [x] مفتاح نشر منخفض الصلاحية فقط في التطبيق.
- [x] لوحة إدارة بجلسة محمية وتحقق دور المدير وسجل تدقيق.
- [x] اختبار دخول المالك فعلياً، وعرض أسباب منع النشر لكل سجل ناقص.
- [x] منع الفهرسة للنسخة الخاصة.
- [x] دوال الإدارة تعمل بصلاحية المستدعي وتخضع لـRLS.
- [x] منع تكرار طلبات Offline وتثبيت هوية الطلب بعد إنشائه.
- [ ] حماية كلمات المرور المسرّبة مفعلة.
- [ ] مراقبة الأخطاء والتحليلات وبيان الخصوصية معتمدة.

## الاختبار والإطلاق

- [x] البناء والتنسيق والاختبارات التلقائية ناجحة.
- [x] فحص آلي لكل المسارات المعلنة.
- [ ] السيناريوهات الواقعية مغلقة وموقعة.
- [ ] لا توجد فجوة P0 أو P1 مفتوحة.
- [ ] موافقة المالك على توسيع الجمهور.
- [ ] تحويل `public_launch_enabled` إلى true بقرار منفصل.

الحكم الحالي: جاهز لبدء Beta مغلقة بعد إنشاء حسابات المختبرين، وغير معتمد بعد للإطلاق العام.
